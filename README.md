<details>
<summary><b>◤ How this page is built</b></summary>
<br />

A GitHub README is sanitized — no `<style>`, no `<script>`, no classes. Every animated element here is an SVG generated by [`charts.yml`](./.github/workflows/charts.yml), because an `<img src="*.svg">` keeps its own stylesheet and keyframes.

- [`render.py`](./.github/scripts/render.py) draws the header, terminal and guestbook cards
- [`lowlighter/metrics`](https://github.com/lowlighter/metrics) renders the contribution calendar and WakaTime breakdown
- [`Platane/snk`](https://github.com/Platane/snk) animates the contribution snake
- The guestbook redraws from issues via [`guestbook.yml`](./.github/workflows/guestbook.yml)

Everything regenerates on a daily cron inside this repo, so no third-party service holds a token.

</details>
